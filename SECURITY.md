# Security policy

## Supported versions

Dothoard is experimental. Security fixes are made on the `main` branch; no
older release branches are currently supported.

## Reporting a vulnerability

Do **not** report suspected vulnerabilities in a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/enriqTS/dothoard/security/advisories/new)
for this repository. Include a clear description, affected version or commit,
reproduction steps or proof of concept, impact, and any proposed mitigation.

Please do not include credentials, private repository URLs, personal paths, or
real dotfile contents in a report. Use placeholders and sanitized examples.

We will acknowledge reports as soon as practical, investigate privately, and
coordinate a fix and disclosure before publishing details. There is no
published response-time guarantee while the project is experimental.
